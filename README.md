# Web Automation Testing with Katalon
Project ini merupakan automation testing pada website e-commerce demo menggunakan Katalon Studio sebagai bagian dari tugas pembelajaran automation testing.

## Testing Website
🔗 https://www.saucedemo.com

## Fitur yang Diuji
1. Login
2. Product Sorting
3. Add to Cart
4. Checkout Process
Setiap test case dilengkapi dengan assertion (verify element dan verify text) untuk memastikan hasil sesuai dengan yang diharapkan.

## Tools
Katalon Studio
Google Chrome
Git & GitHub

## Cara Menjalankan
1. Clone repository ini
2. Buka project menggunakan Katalon Studio
